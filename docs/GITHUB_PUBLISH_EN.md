# GitHub Submission Checklist

1. Create an actual repository owned or accessible by the 3–4-person team.
2. Each real team member clones it and commits their own contributions.
3. Commit application code, unit tests, SQL, `.puml` diagrams, LaTeX sources and PDF reports.
4. Keep local `tasks.db`, Maven `target/`, credentials and temporary build artifacts out of Git (`.gitignore`).
5. Push changes, verify CI results, and save the exact repository URL.
6. Include a contribution register with authentic commit SHAs, and present an actual running demo.

This document cannot serve as evidence that these actions already happened.
