Problem and Scope




    • Small teams need to assign and track tasks.
    • Single-machine Java desktop application.
    • Multiple accounts use one local SQLite file.
    • No real-time online synchronization.




                                                     2 / 16
Assignment Requirements




    • Register, log in and log out.
    • Create, assign, edit, delete and complete tasks.
    • View created or assigned tasks.
    • Persist data with SQLite through JDBC.
    • Use Git, JUnit 5 and documented system design.




                                                         3 / 16
Additional Features




    • Three priority levels: LOW, MEDIUM, HIGH.
    • Optional due dates in YYYY-MM-DD format.
    • Open / completed / high-priority filters.
    • Sorting by task table columns.

Implementation Details




    • Java 11+, Swing, JDBC and SQLite.
    • Parameterized SQL and database foreign keys.
    • Salted PBKDF2 password hashes.
    • Automatic creation of users and tasks tables.

Manual Demo Script




   1. Register Alice and Bob.
   2. Alice assigns a task to Bob.
   3. Bob completes the task but cannot edit/delete.
   4. Alice changes priority, reassigns or deletes the task.
   5. Restart: verify persistence and task filters.

Design Trade-offs




    • Local database: low setup cost, offline use.
    • No multi-device collaboration or backup automation.
    • Permission policy is a stated design choice.
    • Lean MVC-oriented packages for small-coursework scope.
