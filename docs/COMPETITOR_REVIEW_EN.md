# Similar Applications and Feedback Review

The CS341 first-week guidance asks the team to examine comparable task applications and user feedback. The following is a limited design comparison, not a scientific user study.

| Feature | Todoist | Trello | Local Task Tracker |
|---|---|---|---|
| Main task model | Task / project | Cards / boards | Swing task table |
| Deadlines | Supported | Supported | Optional ISO date |
| Priority / labels | Priority | Labels / custom fields | Three priority levels |
| Assignment | Collaboration features | Board/card collaboration | Local accounts in turn |
| Filter/organize | Powerful filtering | Board organization | Three simple filters + sorting |
| Hosting model | Online service | Online service | One local SQLite database |

Sources used during the preliminary research (external links, last checked previously; **not revalidated in this offline build**):
- Todoist pricing/features: https://www.todoist.com/pricing/
- Trello custom cards: https://support.atlassian.com/trello/docs/add-and-customize-cards-and-lists/
- Trello dates: https://support.atlassian.com/trello/docs/adding-dates-to-cards/
- Anecdotal deadline conversation: https://www.reddit.com/r/todoist/comments/1rnydjv/how_do_you_handle_tasks_without_a_real_deadline/
- Anecdotal frustration conversation: https://www.reddit.com/r/todoist/comments/1n5idb4/whats_your_biggest_frustration_with_todoist_right/

**Design consequence:** optional deadlines, simple filters, explicit completion and priority fields. Comments from online forums are individual opinions; they cannot establish representative satisfaction rates. The local coursework app is not presented as equivalent to production collaboration tools.
