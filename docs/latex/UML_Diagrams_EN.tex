\section{Diagram Source and Status}
All seven authoritative diagram definitions are provided as PlantUML \texttt{.puml} files. Each was rendered with PlantUML 1.2025.10 to both SVG and PNG under \texttt{docs/diagrams/}. The figures below use these genuine PlantUML PNG renders; the SVG files are also retained for scalable viewing.

The local application distinguishes visitors, signed-in users, task creators and task assignees. Editing and deletion are restricted to task creators.
