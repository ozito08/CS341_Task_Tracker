\section{Non-Negotiable Final Validation Gates}
\begin{enumerate}
\item \textbf{Java/JDBC/JUnit:} local gate passed with \texttt{mvn -B clean verify}; retain the true console log and Surefire reports.
\item \textbf{Desktop UI:} demonstrate AT-01--AT-08 with the real application and SQLite driver; save screenshots or a recording as evidence.
\item \textbf{PlantUML/PDF:} seven PlantUML sources were rendered and the PDF set rebuilt; perform a human visual review of all pages and GUI acceptance before submission.
\item \textbf{GitHub:} publish the actual repository, verify CI status, and preserve meaningful individual commits from 3--4 real students.
\item \textbf{Presentation:} all team members participate and can explain their contributions and technical decisions.
\end{enumerate}
\section{Evidence Interpretation}
Passing JUnit/JDBC and packaged-JAR SQLite tests establishes the tested application paths only. It does not establish graphical usability, teamwork authenticity, remote GitHub CI, or submission completion. The release remains partially verified until the GUI, extraction/build packaging, and real team/remote requirements are completed.
